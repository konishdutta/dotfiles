# Essential keys

Leader is Space. Press Space and pause for which-key.

| Action | Key |
|---|---|
| Find file / repository grep | Space Space / Space sg |
| Explorer / Oil | Space e / Space o |
| Harpoon add/list | Space ha / Space hh |
| Harpoon jump/cycle | Space h1…h4 / Space hn, Space hp |
| LazyGit | Space gg |
| Diagnostics | Space xx |
| Refactor menu / extract function / variable / inline | Space rs / Space re / Space rv / Space ri |
| Debug start, breakpoint, step over/into/out | F5 / F9 / F10 / F11 / Shift-F11 |
| Debug fallback | Space dc, db, do, di, dO |
| Debug UI / REPL / nearest test / class | Space du / dr / dn / dC |
| Test actions | Space t |
| Codex toggle / prompt context | Space ai / Space as |
| UndoTree | Space u |
| System clipboard yank/paste | Space y / Space Y / Space P |

Use gd for definition, gr for references, K for hover, and [d/]d for diagnostics. Ctrl-d/u and n/N recenter the cursor. Visual J/K moves lines; visual p preserves the yank register. For Python formatting use Space cf.
